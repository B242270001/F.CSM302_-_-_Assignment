## Хэрэглэгчийн интерфейс (UI)

Төслийн хэрэглэгчийн интерфейсийг Python-ийн Tkinter сан ашиглан боловсруулсан. UI нь Sleeping Teaching Assistant симуляцийн үйл ажиллагааг бодит цаг хугацаанд дүрслэн харуулах зориулалттай.

### UI-ийн боломжууд

- **Dashboard:** Орчин үеийн dark theme загвартай интерфейс.
- **TA Status:** Багшийн туслахын Sleeping, Awake, Helping төлөвийг харуулна.
- **Student Animation:** Оюутнуудын хөдөлгөөн болон хүлээлгийн дарааллыг дүрсэлнэ.
- **Waiting Chairs:** Хүлээлгийн сандлуудын эзлэгдсэн болон сул төлөвийг харуулна.
- **Event Log:** Симуляцийн үйл явдлуудыг өнгө, төрөл, цагийн мэдээлэлтэй харуулна.
- **Statistics:** Үйлчлүүлсэн, хүлээж байгаа болон буцсан оюутнуудын тоог харуулна.
- **Performance Chart:** Симуляцийн үзүүлэлтүүдийг графикаар дүрсэлнэ.
- **CSV Export:** Event Log-ийн мэдээллийг CSV файл болгон хадгалах боломжтой.

### Симуляцийн удирдлага

- **Start:** Симуляцийг эхлүүлэх.
- **Pause:** Симуляцийг түр зогсоох.
- **Step:** Дараагийн үйл явдлыг нэг алхмаар харуулах.
- **Reset:** Симуляцийг дахин эхлүүлэхэд бэлтгэж цэвэрлэх.
- **Speed:** Дүрслэлийн хурдыг тохируулах.

### UI-г ажиллуулах

Төслийн үндсэн хавтсанд Terminal нээгээд дараах командыг ажиллуулна.

```bash
python src/ui.py
```

Ингэснээр график интерфейс нээгдэнэ. Start товчийг дарснаар симуляцийн үйл ажиллагааг ажиглах боломжтой.

### UI болон Core-ийн холболт

`ui.py` файл нь `ta_core.py` доторх симуляцийн логиктой холбогдон ажиллана.

Core хэсгээс үүссэн event-үүдийг UI хүлээн авч, багшийн туслах болон оюутнуудын төлөв, хүлээлгийн сандал, статистик мэдээлэл, Event Log-ийг шинэчилдэг.

Ингэснээр олон урсгалын синхрончлолын үйл ажиллагааг хэрэглэгч ойлгомжтой байдлаар ажиглах боломжтой.
